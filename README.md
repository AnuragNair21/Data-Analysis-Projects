# Indian Startup Funding: Data Cleaning & Power BI Analysis

An end-to-end analytics project exploring startup funding in India. I used Python to standardize a raw funding dataset and prepare it for analysis, then built a Power BI report from the cleaned data.

The work focuses on making inconsistent source data more usable: cleaning text fields, aligning categories and locations, converting dates and funding amounts to analysis-friendly types, and exporting a clean CSV for reporting.

## Project workflow

1. Load the source CSV with pandas.
2. Normalize column names and clean inconsistent text, whitespace, and encoded characters.
3. Standardize startup names, city names, industry labels, and investment-stage/type labels.
4. Convert the Excel-style date values into dates and coerce funding amounts into numeric values so malformed entries can be identified as missing.
5. Review the resulting dataset shape and missing-value counts, and inspect the most common cities and investment types.
6. Export the cleaned dataset as `startup_funding_clean.csv` and use it as the source for the Power BI report.

   ```bash

   ```

3. Place the source file at `data/startup_funding.csv`, or update the notebook's input path to match its location.
4. Open `Indian Startup Funding Proj.ipynb` in Jupyter and run the cells from top to bottom.
5. Save the generated cleaned CSV in the location configured in the final notebook cell.
6. In Power BI Desktop, connect the report to the cleaned CSV if you need to refresh the report.

## Data preparation notes

The notebook standardizes several fields, including city, industry, investor, and investment type. It also converts the date and USD amount columns to usable types. Invalid numeric amount entries are coerced to missing values, so they can be reviewed during data-quality checks rather than silently treated as valid amounts.

The notebook currently prints dataset dimensions, missing-value counts, and the most frequent city and investment-type values. These checks offer a quick review of the cleaned data before it is used in the report.
